# 투둥실 프론트엔드 2차 수정 내역
- `/shop` 독립 상점 페이지 추가: 모자/효과/표정 카테고리, 아이템 미리보기, 구매·착용
- `/missions` 미션 페이지 추가: 오늘의 미션, 도전하기, 완료 상태
- 첫 로그인 후 서비스 페이지 진입 시 하루 1회 출석 미션 자동 완료 및 `코인 5개 획득!` 팝업
- 목표 생성, 투두 완료, 소셜 방 입장, 공동 투두 완료, 친구와 사진 촬영 시 미션 보상 팝업
- 소셜 방을 `친구의 투두`와 `공동 투두` 탭으로 분리
- 사진 촬영 배경을 하늘·무지개·꽃·조개 테마로 개선하고 캐릭터 사이 간격 축소
- 프로필 상점 탭을 제거하고 독립 상점으로 이동하는 버튼 추가

주의: 출석/미션/공동 투두/사진 데이터는 백엔드 API가 없어 localStorage 기반입니다. 실제 배포 전 서버 검증 API가 필요합니다.
